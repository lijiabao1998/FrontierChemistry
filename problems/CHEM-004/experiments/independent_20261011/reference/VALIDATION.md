# 化學驗證契約

先凍結每個子任務：分子／材料安全範圍、參照資料及license、溫度／壓力／標準態、電荷與自旋、幾何／構象、方法／基組／力場、資料切分、目標物理量、指標與誤差界。這些條件在結果前寫入，不事後挑基線。

基線守衛：原子計數與電荷一致、能量單位與標準態轉換、幾何合理性、簡單解析極限、網格／時間步／基組／構象收斂、獨立評分實作。電子能不替代Gibbs自由能，低勢能不等於可合成。

計算label與實驗參照分開；DFT模型有自己的系統誤差。資料依化學骨架、反應族、溶劑、材料系統及時間作適當留出，避免同一化合物不同表示洩漏。報MAE以外的分層誤差、區間和假陽性；不得只挑最好的seed。

先做可執行負控制（錯單位／錯電荷／資料重複／不合法幾何）確認validator能紅。新方法、驗證器改動與新結果分開審核。完成benchmark只完成子題；一般機制／發現需同範圍獨立證據。任何濕實驗由合資格單位及適用安全程序處理，本repo不授權執行。
